## 1. 测试策略与自动化流程

采用**四层测试金字塔 + CI 门禁**，全部用例可脱离外部网络确定性执行，另设真实网络端到端冒烟验收：

| 层级 | 覆盖对象 | 执行方式 | 触发时机 |
|---|---|---|---|
| L1 单元测试 | `config` / `time_utils` / `dedup` / `classifier` / `importance` / `fetch_meta` / `translator` / `archive` | `pytest tests/`（Mock HTTP） | 本地每次修改 + GitHub Actions `ci.yml` |
| L2 存储与 FTS5 测试 | `db.py`（SQLite CRUD、双时间查询、FTS5 触发器同步、MySQL DDL 方言生成） | 临时 SQLite 文件 | 本地 + `ci.yml` |
| L3 前后端模板契约测试 | `render.py` + `templates/*.html.j2`（DOM 属性、相对路径、双时间、零外链、原子写入） | `pytest` + BeautifulSoup 校验 | 本地 + `ci.yml` |
| L4 流水线 E2E & 真实冒烟 | `pipeline.py` 完整闭环（Mock 确定性 E2E + 真实三源网络实测 + 连续二次运行幂等校验） | `pytest` + CLI 实测 | 交付前必跑 |

## 4. 验收准出标准

1. `pytest -v` 全部自动化测试 **100% 通过**，0 失败、0 跳过关键用例；
2. 真实三源网络冒烟实测通过（Bloomberg / WSJ 新端点 / Reuters GN 均产出，二次运行 0 重复，翻译成功率 ≥ 90%）；
3. 生成的 `index.html`、`daily/*.html`、`archive/index.html` 均满足自包含零外链与前后端契约校验。
